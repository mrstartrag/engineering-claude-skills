Top 20 Claude skills for software engineering

A weekly curated list. Software engineering only, no fluff.
Last updated Oct 28, 2026. Next curation Saturday Oct 31, around 9am PT.
Rule: always 20. One in, one out. Dropped skills move to archive, never deleted.

How to use this list

  • Start with one workflow framework from 1-5, not all five.
  • Add the official Anthropic skills you actually need from 8-12.
  • Add one skill per real pain point after that: UI, understanding code, context, tokens.
  • Install only what you will use. Every enabled skill costs context.

Install: /plugin marketplace add anthropics/skills, or copy a skill folder into ~/.claude/skills/. Check the source repo first, commands change. This is an index, not a copy. Each entry links to its source. Star counts are from Oct 27-28 and move daily.

Workflow and methodology

1Superpowers (about 306k stars)

Plan first, test-driven development, systematic debugging, subagent-driven work, verify before finishing.

Use when: you want Claude Code to act like a disciplined senior engineer instead of jumping straight to code.

2Matt Pocock Skills

Small composable skills for real engineering work.

Use when: you want bite-size skills you can adopt one at a time.

3Addy Osmani Agent Skills (about 101k stars)

Production-grade spec, build, test, ship workflows.

Use when: you want a shipping workflow, not just a coding helper.

4GSD - Get Shit Done

Spec-driven work with tight context.

Use when: you want a spec before code and context kept small.

5BMAD-METHOD

Agile AI-driven development method.

Use when: you want an agile, role-based method for bigger builds.

Thinking and discipline

6Karpathy Skills

Think before coding, simplicity first, small surgical changes, goal-driven work. A bug fix means writing a reproducing test first.

Use when: you keep getting 1000-line fixes for 100-line problems. Check the source before installing, these rules float around in several mirrors.

7Planning with Files

Breaks tasks into steps and tracks progress in files.

Use when: a coding task runs longer than a few minutes and Claude loses track.

Official Anthropic, software engineering only

From anthropics/skills (about 184k stars). Only the engineering ones made the list.

8skill-creator

A skill that writes skills, following Anthropic's own authoring practice.

Use when: you catch yourself explaining the same procedure twice.

9mcp-builder

Guide for building good MCP servers.

Use when: you need Claude to reach an API, database, or outside service.

10frontend-design

Distinctive, production-grade UI direction.

Use when: you build web interfaces and want to avoid generic-looking pages.

11artifacts-builder

Build complex HTML artifacts with React, Tailwind, shadcn.

Use when: you build interactive artifacts or web apps in Claude.

12webapp-testing

Test local web apps with Playwright for UI checks and debugging.

Use when: you need browser-driven QA before shipping a web app.

Frontend and UI

13UI-UX Pro Max

Design intelligence: styles, palettes, UX rules.

Use when: your UI looks AI-made and you want a real design system.

14Taste Skill

Strict anti-slop rules for landing pages.

Use when: you want taste and restraint, not more components. Note: blind tests in Oct 2026 were mixed on this one, judge it on your own brief.

Understanding, docs, context

15Understand-Anything

Turns a codebase into an interactive knowledge graph you can explore and ask about.

Use when: you are onboarding to an unfamiliar codebase. Search the name on GitHub, it has several mirrors.

16Context7

Keeps current library docs in front of the model.

Use when: Claude keeps using outdated library APIs.

17Claude-Mem

Persistent memory across sessions.

Use when: Claude forgets your project between sessions.

18Diagram Design (about 53k stars)

Architecture, flow, org, and timeline diagrams, 44 types, exports to HTML, SVG, PNG.

Use when: you need clean architecture diagrams from a codebase or a brief.

Efficiency and harness

19Caveman

Cuts output tokens hard while keeping technical accuracy.

Use when: you are hitting usage limits and want shorter output.

20ECC

Agent harness tuning: skills, memory, security, research-first workflow.

Use when: you want one harness setup across Claude Code, Codex, Cursor, and similar tools. Search "affaan-m/ecc" on GitHub, it has mirrors.
